## 📌 Project Overview

This project presents a complete **Exploratory Data Analysis (EDA)** of a healthcare dataset containing **54,966 patient records**.

The goal is to:
- Clean raw healthcare data  
- Identify key trends and patterns  
- Generate actionable business insights  

---

## 📊 Key Metrics

| Metric | Value |
|------|------|
| 👥 Total Patients | 54,966 |
| 💰 Total Billing | $1.4 Billion |
| 🏥 Avg Stay | 15.5 Days |
| 📅 Time Period | 2019 – 2024 |
| ⚠️ Refund Cases | 106 |

---

## 🔍 Key Analysis

### 📅 Time Analysis
- Peak billing year: **2020**
- Highest admissions: **July & August**

### 🦠 Medical Conditions
- Highest revenue: **Diabetes**
- Balanced distribution across conditions

### 🛡️ Insurance Providers
- Top contributor: **Cigna**
- Even distribution across providers

### 👤 Demographics
- Gender split: **~50/50**
- Adults contribute the highest billing

### ⏳ Hospital Stay
- Average stay duration: **15.5 days**
- Longer stays linked to higher billing

---

## ⚠️ Data Issues Identified

- Negative billing values (refund cases)
- Duplicate records
- Inconsistent text formatting
- Date format inconsistencies

---

## 🧹 Data Cleaning Steps

- Removed duplicate records  
- Standardized text values  
- Handled negative billing (refund logic)  
- Extracted Month, Day, Year  
- Created Age Brackets  
- Calculated Length of Stay  

---

## 💡 Key Insights

- 📈 2020 generated the highest revenue  
- ☀️ Summer months show peak hospital load  
- 💊 Diabetes is the most expensive condition  
- ⚠️ Refund records identified in dataset  
- 👨 Adults drive ~44% of total revenue
